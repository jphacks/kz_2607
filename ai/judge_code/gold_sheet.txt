# 【強さ】  気持ちの強さ 0〜1（例: 0.6）

# 【話し方】敬語の度合い, 関西弁の度合い を 0〜1 で（例: 0, 0.8）
# 【反応】  直前のペットの発言への反応  共=共感 ツ=ツッコミ ボ=ボケ 褒=褒める／なければ「なし」
