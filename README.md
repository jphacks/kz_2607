## 製品概要
### 背景(製品開発のきっかけ、課題等）
人とのつながりを作るきっかけや、会話を始めるきっかけは、日常の中では意外と少ないものです。
そこで、愛着を持って育てたペットが人と人の間を旅し、思い出をつないでいく仕組みを考えました。自分のもとを離れたあとも成長を見守れることで、一度の出会いから続くつながりを目指しています。

### 製品説明（具体的な製品の説明）
M5Stack Core2とスマートフォンを使い、会話を通じてペットを育て、ほかの人へ送り出すサービスです。
6つの質問に答えると、回答に応じた性格と見た目を持つペットが誕生します。ペットは会話を重ねて成長し、覚えた言葉や思い出を持ちながら、次の人のもとへ旅立ちます。
最初に育てたペットは、手元を離れたあともアプリから見守れます。「はじまり」「つながる思い出」「いま」を通じて、自分との思い出から現在までの歩みを振り返れます。
### 特長
#### 1. 特長1　あなたの回答から生まれるペット
活発さ・親しみ・おしゃべり・論理・好奇心・夜型の6軸から性格を決定します。体・目・口のパーツを組み合わせ、性格や成長段階に応じた姿を表現します。
#### 2. 特長2　会話で育ち、人から人へ旅をする
ペットとの会話が成長につながります。育てたペットを交換することで、次の人へと思い出をつないでいきます。
#### 3. 特長3　離れてからも見守れる
最初に育てたペットが、今どの世代にいて、どのような思い出を重ねているかを確認できます。手紙でもペットの歩みを受け取れます。

### 解決出来ること
* ペットを共通の話題にして、人と交流するきっかけを作る
* 日々の会話を、成長や思い出として残す
* 交換後も成長を見守れることで、育てたペットとのつながりを保つ
### 今後の展望
ペットの表情や動き、会話の幅を広げ、個性をより感じられる体験を目指します。また、実機での接続・交換の安定性を高め、イベントやコミュニティなど、人が集まる場での利用を検証していきます。
### 注力したこと（こだわり等）
* 質問への回答を性格と見た目につなげ、「自分が誕生させたペット」と感じられる体験を設計しました。
* 自分との思い出・歴代の持ち主との思い出・現在の思い出を分け、ペットが歩んだ時間を伝える構成にしました。
* 他の持ち主に関する情報は名前をぼかすなど、思い出の共有とプライバシーの両立を意識しました。

## 開発技術
### 活用した技術
#### API・データ
* Firebase Authentication：ユーザー認証
* Cloud Firestore：ペット情報、性格、会話・思い出、交換履歴の管理
* Cloud Functions for Firebase：誕生、成長、交換、見守りなどの処理
* 生成AI API：会話応答や誕生プロフィール、思い出・手紙の文章生成

#### フレームワーク・ライブラリ・モジュール
* Flutter / Dart：スマートフォンアプリ
* Python：バックエンド処理
* Bluetooth Low Energy（BLE）：スマートフォンとCore2の通信

#### デバイス
* M5Stack Core2
* スマートフォン
