# 見守る画面の本番連携

- getFirstPet を asia-northeast1 の Callable として引数なしで呼ぶ。
- CloudFunctionsService の既存認証を使い、ログイン中のUIDを維持する。M5接続・deviceIdは不要。
- 最初に作った1体の決定と、ほかの飼い主の情報の匿名化はサーバーが行う。
- name未設定は「名前はこれから」。petIdがnullなら空状態を表示。現在の端末の子やサンプルで補わない。
- 表示デザインは既存のカード・余白・3タブを維持。画像はホームと同じパーツ合成を使用。
- はじまりは1代目、つながる思い出は2代目から現在の1代前、いまは現在の代。
- 思い出の本文はAPIから返された文をそのまま表示。各代最大10件で、思い出のない代は返されない。
- 日付がnullの場合は日付を補完しない。APIに更新時刻がないので架空の「今日更新」を表示しない。
- withYouから、現在自分のもとにいるかを表示する。
- 画面を開いた時、アプリ復帰時、下への引っ張り操作で再取得。
- 読み込み中・空状態・エラー・再試行に対応。エラー詳細には関数名・code・reasonを表示。
- appearance.tertiaryがあれば口に使用。旧レスポンスで未設定のときだけsecondaryを口にも使う。
- 本番の呼び出しと実機での画面確認は別途必要。
